# Distributed E-Commerce Transaction Analytics

## Project Overview
A Big Data Analytics project using Hadoop HDFS and Hadoop MapReduce to analyze e-commerce transactions on a three-node cluster consisting of one master and two worker nodes.

## Objectives
- Store transaction data in HDFS.
- Demonstrate distributed storage and processing.
- Analyze revenue, products, countries, and monthly sales.
- Verify cluster health and HDFS block locations.

## Technology Stack
- Apache Hadoop 3.3.6
- HDFS
- Hadoop MapReduce
- Docker
- Python
- Git and GitHub

## Dataset
UCI Online Retail dataset:
https://archive.ics.uci.edu/dataset/352/online+retail

The raw dataset is kept locally and will be uploaded to HDFS. It is excluded from Git commits to avoid storing the full archive in the repository.
